# Bondy Connect SDKs

The Bondy Connect SDK is Bondy's own client library. A component uses it to open a session with a Bondy router, and then to call and register procedures and to publish and subscribe to topics.

There is one SDK for each language. Pick yours.

<SdkGallery />

## Examples in your language

The how-to guides and the concept pages show their examples with one tab for each language. Pick a tab, and every example on the site follows your choice.

## Other languages

Bondy speaks standard WAMP, so a component in a language without an SDK connects with a community WAMP library. [WAMP Client Libraries](/connect/reference/clients/index) lists the ones known to work with Bondy.
