# Reference

Information-oriented material to consult while working, not to read start to
end.

- [WAMP Client Libraries](/wamp/reference/clients/index) — what to use to
  speak WAMP from your language.
- [Bondy Connect](/wamp/reference/clients/bondy_connect) — the complete,
  task-grouped API reference for Bondy's own BEAM client: every function,
  option and error shape.

Bondy's own administration API — creating realms, users and grants — is not
protocol material. It lives in
[Bondy Router → WAMP API](/router/reference/wamp_api/index).
